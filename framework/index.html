    Framework overview¶

    newsegsmodelframework is the modelling library that underlies the NewSEGS software. It can be used on its own (for example in scripts or notebooks) and has no dependency on the web application.

    flowchart LR
    project["NewsegsProject"] -->|"contains 1..n"| metamodel["NewsegsMetaModel"]
    project -->|"owns"| sens["DSAComponent<br/>PSAComponent"]
    metamodel --> model["NewsegsModel"]
    metamodel --> finance["NewsegsFinance"]
    metamodel --> variables["Variables"]
    metamodel -->|"owns"| optim["OptimComponent"]
    finance -->|"reads results of"| model
    model --> grid["NewsegsGrid"]
    model --> gen["NewsegsGeneration"]
    model --> cs["NewsegsCS"]
    model --> env["Local and wider<br/>environment servers"]
    variables -. "set values in" .-> model
    variables -. "set values in" .-> finance
    Package Contents Reference
    core Base classes, serialisation, revision tracking, time, location and environment Core components
    newsegsgrid, newsegsgeneration, newsegscs Model modules - grid, generation, consumption and storage Modules
    newsegsmodel Assembles the modules into an energy model Model
    newsegsfinance Finance model and finance data Finance
    newsegsvariable Variables - statistical characterisations of parameters Variable
    newsegsmetamodel, newsegsproject Bind model, finance and variables; collect metamodels Metamodel and Project
    newsegssensitivity, newsegsstats DSA, PSA, optimisation and statistics Statistics and Sensitivity
    util Helper functions Utilities
    plugins Registry of project types Plugins
    constants Framework and model constants

    Implementations specific to the Sprake energy model are prefixed sprake (e.g. SprakeModel, SprakeGeneration, SprakeCS, SprakeFinance) and sit alongside the abstract Newsegs... base classes.

    Lightweight classes¶

    For most of these classes there is a Lightweight... counterpart (LightweightNewsegsModel, LightweightNewsegsMetaModel, LightweightNewsegsProject, LightweightVariable, LightweightNewsegsFinance) holding only the information needed to describe and display the object, without the machinery needed to run it. The web app uses these where it does not need to run a model, which keeps page loads fast.
